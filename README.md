# Blue Funk / Peur bleue

Sharks in Sydney, plane crashes and everyday risks (roads, skin cancer, drowning) compared on one scale, in micromorts:
a one-in-a-million chance of dying. Includes risk factors and a personal calculator.

- English: https://robinlietar.github.io/peur-bleue/
- Français : https://robinlietar.github.io/peur-bleue/fr/

The site is two self-contained HTML pages (`index.html` and `fr/index.html`), served by GitHub Pages.
Data were gathered in October 2026; each page lists its sources and explains how the figures are calculated.
They are population averages, not personal risks: check the sources before quoting.
