# Blue Funk / Peur bleue

Sharks in Sydney, plane crashes and everyday risks (roads, skin cancer, drowning) compared on one scale, in micromorts:
a one-in-a-million chance of dying. Includes risk factors and a personal calculator.

- English, flying version: https://robinlietar.github.io/peur-bleue/
- English, shark version: https://robinlietar.github.io/peur-bleue/sharks/
- Français, version avion : https://robinlietar.github.io/peur-bleue/fr/
- Français, version requins : https://robinlietar.github.io/peur-bleue/fr/requins/

The site is four self-contained HTML pages, served by GitHub Pages. The two versions share the same content;
only the headline, the key number and the order of the sharks and flying sections change.
Data were gathered in October 2026; each page lists its sources and explains how the figures are calculated.
They are population averages, not personal risks: check the sources before quoting.
